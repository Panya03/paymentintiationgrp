# READ THIS MANOJ

Here’s a clear mapping of which CSS file is used by which JS page in your project:

---

### CSS & JS Usage Mapping

- **signUpPageStyles.css**
  - Used by: `SignUpPage.js`
  - Handles all styles for the sign-up page (background, bars, logo, card, buttons, etc.)

- **customPageStyles.css**
  - Used by: `CustomPage.js`
  - Handles all styles for the login page, dialog overlays, animated borders, and related UI.

- **accessibilityToolsStyles.css**
  - Used by: `AccessibilityTools.js`
  - Handles styles for the floating accessibility tools widget (contrast, font size, readout).

---

Each JS file imports its corresponding CSS file at the top.
If you need a summary for any other files, just ask!
